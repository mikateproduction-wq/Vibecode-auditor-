Comment ça marche
  1. Le bouton Analyser est directement connecté à la checklist des 160 points : chaque fichier importé est scanné à la recherche des 160 patterns (UI/UX + code backend).
  2. Les .apk / .aab sont décompressés en local (JSZip, dans le navigateur) : manifest, ressources et bundle JS/assets sont inspectés en texte.
  3. Aucune donnée ne quitte votre machine tant que l'onglet Chat IA n'est pas utilisé (celui-ci nécessite une connexion + votre propre clé API).
  4. Le score final = 100 − nombre de red flags détectés, pondéré par sévérité.
Référentiel : 160 signaux de "vibecoding" — 110 points UI/UX & design (incohérences visuelles, navigation, responsive, animations, loading, erreurs, fuites techniques, auth, stabilité, assets, branding, permissions, i18n) + 50 points niveau code (API/backend, base de données & RLS, CI/CD & supply chain, tests, dépendances vulnérables, architecture logicielle, infra & déploiement, documentation).

Aucune analyse effectuée. Rendez-vous dans l'onglet "Analyse".
