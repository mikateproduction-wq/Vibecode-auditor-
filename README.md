Auditeur Vibecode
Un outil d'analyse et d'audit de code interactif concu pour inspecter vos fichiers source directement dans votre navigateur.

Description
Auditeur Vibecode permet de scanner, analyser et evaluer la qualite de votre code. Grace a une interface web legere, il offre un apercu simple et efficace de la structure de vos projets et signale les points d'amelioration.

Fonctionnalites
Analyse de code rapide et intuitive

Interface web accessible sans installation ni dependances lourdes

Visualisation claire des resultats d'audit

Prise en charge des projets web et scripts de base

Contenu du Depot
index.html.html : Page principale contenant l'interface et la logique d'audit

README.md : Documentation du projet

Installation et Utilisation
Cloner le depot :
git clone https://github.com/mikateproduction-wq/Auditeur-Vibecode.git

Lancer l'application :
Ouvrez simplement le fichier index.html.html dans votre navigateur web.
